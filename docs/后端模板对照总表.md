## 二、统一接口面（7 套完全一致）

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/sso/authorize` | 公开，302 |
| GET | `/sso/callback` | 公开，302 |
| GET | `/api/auth/me` | 公开，未登录返回空对象 |
| POST | `/api/auth/logout` | 公开，无会话时也成功 |
| GET | `/api/bff/me` | 公开，未登录返回空对象 |
| GET/POST/PUT/DELETE | `/api/users`、`/api/users/{id}` | 需登录 |
| GET/POST | `/api/admin/users`、`/api/admin/users/recycle` | 需管理员 |
| PUT | `/api/admin/users/{id}/status` | 需管理员 |
| DELETE | `/api/admin/users/{id}`、`/api/admin/users/{id}/purge` | 需管理员 |
| POST | `/api/admin/users/{id}/restore` | 需管理员 |
| GET | `/api/demo/admin`、`/api/demo/user` | 管理员 / 已登录 |

## 三、统一响应契约

```json
{"code": 200, "success": true, "message": "操作成功", "data": {}, "timestamp": 1720000000000}
```

- HTTP 状态恒 200，业务码在 `code`
- `ResultCode`：200 / 400 / 401 / 403 / 404 / 405 / 500 / 1000 / 1001 / 1002 / 1003
- 分页：`{pageNum, pageSize, total, pages, records}`，默认 `1/10`，`pageSize` 上限 500
- 鉴权失败约定：未登录 401、非管理员 403、账号被禁用 403

## 四、本地用户管理（方案B）

| 能力 | 实现 |
| --- | --- |
| `users` 表 | `uid VARCHAR(64)` 唯一，`role`（ADMIN/USER）、`status`（1 启用 / 0 禁用）、`deleted`（0/1 回收站）、`version`（乐观锁） |
| 自动注册 | SSO 首次登录按 `sub` 建 `uid`，默认角色 `USER` |
| 角色来源 | `SSO_ADMIN_UID`（默认 `1`）判定管理员，本地 `role` 落库 |
| 回收站 | `DELETE /{id}` 软删除（`deleted=1`）→ `/recycle` 列表 → `/restore` 恢复 → `/purge` 物理删除 |
| 种子数据 | `sql/init.sql` 各框架共用：`(1,'1','ADMIN',1,0)` |

## 五、SSO 接入核对清单

- [x] `/sso/authorize`：生成 `state` 存会话，302 到 `SSO_AUTHORIZATION_URI`
- [x] `/sso/callback`：校验 `state` → `client_secret_post` 换 token → `/userinfo` 取 `sub` → 身份与 token写入会话 → 注册/复用本地用户 → 302 `SSO_LOGIN_SUCCESS_URL`
- [x] Bearer 校验：`jose`（Node/Nest）、`firebase/php-jwt`（PHP）、手写 JWKS 验签（Go），均校验 `iss`
- [x] 登出：revoke `refresh_token`（无则 `access_token`）→ 销毁会话 → 返回 `ssoLogoutUrl`
- [x] JWKS 缓存：PHP 10 分钟、Go/FastAPI 进程内缓存
- [x] 回调地址统一 `http://localhost:8080/sso/callback`，需在 SSO 控制台登记
- [ ] 真实 client_id / client_secret（需在 AntX passport-sso 控制台创建应用后填入 `.env`）

## 七、配套前端 `vue/`

| 关注点 | 实现 |
